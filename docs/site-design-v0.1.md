# サイト設計メモ v0.1

## 目的

企業の採用サイトをテーマに、AI検索とLLMOについて専門知識のない人でも構造として理解できる「デジタル科学館」をつくる。

## 主役となる検索者

会社名や求人名をすでに知っている求職者だけでなく、

- 未経験から始めたい
- 土日休みがよい
- 子育てと両立したい
- 残業が少ない仕事を探したい

といった希望から、AIに会社・求人そのものを探してもらう探索型検索を主役にする。

## 説明方針

仕組みは一般論。
具体例は採用サイト。

基本表示は日本語。
英語・専門用語は深掘り用の補助ラベル。

説明は、

1. ひとことで
2. やさしい説明
3. 採用サイトでは？
4. 良い例・惜しい例
5. 詳しく知る

の順に深くする。

## UI原則

- 現在地を失わせない
- どこからでも別セクションへ移動できる
- 一画面に情報を詰め込みすぎない
- hoverは補助、click/tapを本体にする
- 詳細はモーダルではなく右サイドドロワーを基本とする
- 大きな表は概要→詳細の段階表示にする

## LLMOの6関門

1. Findable
2. Understandable
3. Relevant
4. Extractable
5. Trustworthy
6. Representable

LLMOを「この6関門で発生する情報損失を減らす活動」として説明する。

## LLMO施策5群

- Technical
- Semantic / Entity
- Content
- Evidence / Trust
- External / Web Ecosystem

## v0.1の目的

完成形を作ることではなく、
ブラウザ上で実際の情報密度・ナビゲーション・説明順を触りながら検証できる箱を作ること。
